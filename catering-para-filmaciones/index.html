Preguntas frecuentes

Antes de cotizar.

¿Pueden trabajar en exteriores o locaciones temporales?

Sí. Revisamos accesos, energía, agua, espacio y ventanas de servicio para proponer el formato adecuado.

¿Manejan box lunch para rodaje?

Sí. Es una opción útil para traslados, llamados escalonados y consumo rápido.

¿Pueden dejar coffee break durante toda la jornada?

Sí. Podemos instalar una estación de servicio continuo según el alcance.
